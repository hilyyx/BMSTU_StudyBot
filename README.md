# BMSTU StudyBot

Обычный Telegram-бот для ИУ7-13Б. Первая версия: регистрация по приглашению и расписание в личном чате.

## Локальный запуск (PowerShell)

Требуется Python 3.11 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Заполните `.env`:

- `BOT_TOKEN` — токен бота, созданного через [BotFather](https://t.me/BotFather).
- `OWNER_ID` — ваш числовой Telegram ID, не username. Владелец регистрируется без приглашения. После запуска команда `/id` показывает ID отправителя, даже до регистрации.

Учебные недели считаются от 31 августа 2026 (первая неделя текущего осеннего семестра). Нечётные — числитель, чётные — знаменатель. Например, 14–20 сентября — третья неделя, числитель. Бот показывает номер и тип недели автоматически; настройки недели в `.env` не нужны. Начало семестра задано в `studybot/schedule.py` (`SEMESTER_START`); для следующего семестра потребуется обновить эту дату. Расписание представляет недельный шаблон: праздники, отмены и границы семестра отдельно не учитываются.

```powershell
.\.venv\Scripts\python.exe -m studybot
```

Остановить: Ctrl+C. Одновременно запускайте только один экземпляр с этим токеном.

## Первый вход

1. Откройте личный чат с ботом и отправьте `/start`.
2. Введите имя и фамилию, затем номер в журнале (1–30). Перед вводом номера бот отправит фото журнала, чтобы можно было найти свою строку.
3. Как владелец, отправьте `/invite 28` для создания 28 отдельных одноразовых кодов. `/invite` создаёт один код.
4. Передайте каждому студенту отдельный код. Студент отправляет `/start`, затем код и данные профиля.

После регистрации доступны сегодня, завтра, текущая и следующая недели, профиль и `/edit_profile`. Незавершённая регистрация переживает перезапуск. Код расходуется при активации, а продолжить регистрацию можно через `/start`.

Номер в журнале задаётся самостоятельно и не может повторяться. Если номер уже занят, бот попросит проверить его; при ошибке обратитесь к владельцу. Роль студента сохраняется в базе; домашка и её редактирование будут следующим этапом.

Владелец видит кнопку «👥 Моя группа» и может отправить `/group`. Список содержит все вошедшие аккаунты, включая незавершённые регистрации: имя, номер, Telegram username, ID и роль. Username обновляется при обращении пользователя к боту; если его нет, показывается «не указан». У ранее зарегистрированных участников он появится после следующего сообщения боту. Участники, которые ещё не активировали приглашение, в список не попадают.

При первом запуске обновления старые повторяющиеся номера сбрасываются у всех участников конфликта; имена и доступ сохраняются. До сброса создаётся резервная копия базы в её каталоге. Затем база запрещает повторение номеров, включая одновременную регистрацию.

## Расписание

Источник — [публичный API МГТУ](https://lks.bmstu.ru/lks-back/api/v1/schedules/groups/ab0c54d0-1624-11f1-9d39-005056aae53e/public). Используется время Москвы. API проверяется при старте, затем расписание обновляется раз в час. При сбое бот показывает последнюю сохранённую копию с предупреждением; повторные попытки — не чаще раза в пять минут.

SQLite находится в `data/bot.sqlite3`, хранит пользователей, хеши кодов приглашения и расписание. Каталог `data/`, `.env` и виртуальное окружение исключены из Git. Для переноса на сервер сохраните `.env` и базу.

## Структура

- `studybot/config.py` — конфигурация и проверка настроек.
- `studybot/database.py` — пользователи, приглашения, кеш расписания.
- `studybot/schedule.py` — API, чередование недель и отображение.
- `studybot/handlers.py` — регистрация и команды Telegram.
- `studybot/__main__.py` — запуск и фоновые обновления.
- `studybot/assets/group_journal.jpg` — фото журнала для выбора номера при регистрации и изменении профиля.

Интерфейс использует [aiogram 3](https://docs.aiogram.dev/en/latest/), получение сообщений — polling.

В `handlers.py` функции `parse_number`, `schedule_dates` и `send_day` отвечают за проверку чисел, выбор дат и отправку длинного расписания. Сами обработчики описывают шаги диалога. В `schedule.py` номер учебной недели вычисляет `academic_week`, а её тип — `week_type`.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Для проверки в Telegram нужны реальные `BOT_TOKEN` и `OWNER_ID`. После запуска проверьте регистрацию владельца, активацию одного приглашения вторым аккаунтом и кнопки расписания.
